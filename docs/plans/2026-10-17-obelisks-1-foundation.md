## Pivotal constraints

- Build time is about four hours in two windows: from 10:50 AM to 2 PM (Phase 1) and from 3 PM to 5:15 PM (Phase 2). Headset slots are fixed: Vision Pro from 2 PM to 3 PM, Quest 3S from 5:30 PM to 6:30 PM. Submission 6:30 PM (user; verified: moltenhack.com `#calendar`).
- WebXR, `getUserMedia`, and Safari 26+ `SpeechRecognition` need a secure context. `localhost` is secure; a LAN IP is not. Headsets reach the laptop only over a real-certificate HTTPS URL (verified: lane `webxr-devices`).
- No DOM inside an immersive session on either headset: every label is in-scene text (verified: WebKit has no DOM-overlay IDL; Quest DOM overlay unsupported per community threads, medium confidence).
- Hermes stays bound to `127.0.0.1:9119` with a fixed `HERMES_DASHBOARD_SESSION_TOKEN`; a public bind requires an auth provider and `--insecure` is a no-op (verified: `hermes_cli/subcommands/dashboard.py` at `59ee4989`). The relay and the page have no auth at all: the tunnel link is the share link (user).
- Thinking and tool events reach the wire only when the host config has `display.show_reasoning: true` and `display.tool_progress: true` and the model emits reasoning (verified: lane `bighelp-protocol` reading `tui_gateway`; gate names medium confidence).
- Code is written during the event; the plan and this document are not code (verified: moltenhack.com `#submit` rules).
- Wireframe look only; no visual design pass today (user).
- Claude Code subagents and workflows ship in this MVP beside the Hermes chat, and a new harness must plug in as one source module without touching the client (user).
- This plan must land every seam the other five plans build on: the protocol module, the feature loader, the source and command loaders, the `bus` event names, `getObelisk(sid)`, `bus.selected`, and `bus.selectedSlab` (user: "the first plan must lay down the foundation").

## New domain terms · Recommended ADRs

Harness source (one module per agent harness), obelisk (one session or agent), child obelisk (a fork or a subagent), slab (one message or tool call in an obelisk), pylon (a fixed tool landmark), projectile (the tool-call flight from slab to pylon), relay (the laptop process between Hermes and every client), room (the shared scene), REPLAY mode (relay plays a recording), SYNTHETIC mode (relay plays a generated fixture). ADRs: none today; if the relay-in-the-middle survives the hackathon, record it as ADR 0001.

## Commander's Intent

- **Purpose:** lay down every seam so five plans can build at once, and show a synthetic room of obelisks in both headsets and on the laptop before 2 PM.
- **Method:** one Vite bundle with a glob-loaded feature set and one Node relay with glob-loaded sources and commands; a synthetic source so the room renders with no harness; obelisks with three-band LOD and child placement; VRButton entry with a select-ray that works for Vision Pro transient pointers and Quest controllers; a laptop mode with OrbitControls and a text box.
